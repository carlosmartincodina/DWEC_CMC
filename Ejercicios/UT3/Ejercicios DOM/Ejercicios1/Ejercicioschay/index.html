Ejercicio 1: Lista de tareas

Crea un programa que permita añadir tareas a una lista ordenada.

Al pulsar el botón "Añadir tarea", el texto del input debe añadirse como un nuevo elemento de la lista.

Si el campo está vacío, no se debe añadir nada.

    Ejercicio 2: Números aleatorios

    Crea un programa que genere números aleatorios entre 1 y 100.

    Cada vez que se pulse el botón, se añadirá un nuevo número a la lista.

    Añade también un botón para borrar todos los números de la lista.

      Ejercicio 3: Crear casillas de verificación

      Introduce un número y pulsa el botón para crear esa cantidad de checkbox.

      Cada checkbox debe tener una etiqueta con su número correspondiente.

      Si introduces un número inferior a 1 o un valor no válido, muestra un mensaje de error mediante alert.

      Ejercicio 4: Mis asignaturas favoritas

      Introduce el nombre de una asignatura y su nota.

      Al pulsar "Añadir asignatura", se debe crear un elemento que muestre el nombre y la nota.

      No se deben permitir asignaturas repetidas.

      Utiliza un Set para almacenar las asignaturas introducidas.

        Ejercicio 5: Formulario de búsqueda de viajes

        Crea un formulario para buscar viajes entre dos ciudades.

        Requisitos:

        • El origen y el destino son obligatorios.
        • La fecha de ida no puede ser anterior al día actual.
        • Si "Solo ida" está marcado, la fecha de vuelta debe deshabilitarse.
        • Si no está marcado, la fecha de vuelta debe ser igual o posterior a la fecha de ida.
        • Los errores deben mostrarse mediante alert.
        • Si los datos son válidos, muestra la búsqueda en el área de resultados.
        • Después de una búsqueda válida, limpia el formulario.

        Ejercicio 6: Lista de la compra

        Crea una lista de la compra que permita añadir productos.

        Los productos deben aparecer ordenados alfabéticamente.

        Al pulsar sobre un producto, este debe eliminarse de la lista.

        No se deben añadir productos vacíos ni productos repetidos.

          Al llegar al azul, el siguiente clic debe volver al rojo.

          Ejercicio 8: Mostrar y ocultar contenido

          Crea un botón que permita mostrar u ocultar un texto.

          Cuando el texto esté visible, el botón debe mostrar "Ocultar texto".

          Cuando el texto esté oculto, el botón debe mostrar "Mostrar texto".

          Este texto debe poder mostrarse y ocultarse al pulsar el botón.

          Ejercicio 9: Contador

          Crea un contador que empiece en cero.

          Debe tener tres botones: incrementar, decrementar y reiniciar.

          El valor del contador debe actualizarse sin recargar la página.

          Ejercicio 10: Registro de alumnos

          Crea un formulario para registrar alumnos con su nombre y edad.

          Al pulsar "Registrar", se debe añadir el alumno a una tabla con las columnas Nombre y Edad.

          El nombre no puede estar vacío y la edad debe ser igual o superior a 18.

          Si los datos no son válidos, muestra un mensaje mediante alert.
